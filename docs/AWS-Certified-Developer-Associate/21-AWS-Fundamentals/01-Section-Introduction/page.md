# Section Introduction

Source: https://notes.kodekloud.com/docs/AWS-Certified-Developer-Associate/AWS-Fundamentals/Section-Introduction/page

This article explores AWS fundamentals, covering cloud computing, core AWS concepts, global infrastructure, and methods for accessing AWS services.

In this article, we explore the fundamentals of AWS, starting with an overview of cloud computing and progressing to the core concepts of Amazon Web Services (AWS). You'll learn about the purpose and benefits of AWS, how its global infrastructure supports scalable and reliable applications, and the various methods available for accessing AWS, including the Console, CLI, and SDK.

![The image is a section introduction slide listing four topics: "What is the Cloud?", "What is AWS?", "AWS Global Infrastructure", and "How to access AWS using Console, CLI, and SDK".](https://kodekloud.com/kk-media/image/upload/v1752858265/notes-assets/images/AWS-Certified-Developer-Associate-Section-Introduction/cloud-aws-introduction-topics.jpg)

> **lightbulb** This section provides a high-level introduction to AWS concepts which will help you understand how AWS services integrate to build resilient cloud architectures.

Following the initial overview, we introduce the Virtual Private Cloud (VPC), an essential component for understanding AWS networking. The discussion then briefly covers additional vital AWS services such as S3, EC2, Route 53, and AWS CloudFormation. This concise roundup of core services sets the stage for diving into more advanced topics in subsequent sections.
