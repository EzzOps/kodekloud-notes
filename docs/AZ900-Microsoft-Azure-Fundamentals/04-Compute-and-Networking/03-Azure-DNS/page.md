# Azure DNS

Source: https://notes.kodekloud.com/docs/AZ900-Microsoft-Azure-Fundamentals/Compute-and-Networking/Azure-DNS/page

Azure DNS is a hosting service for DNS domains that provides reliable, high-performance name resolution using Microsoft Azures global infrastructure.

Azure DNS is a hosting service for DNS domains that leverages Microsoft Azure's global infrastructure to provide reliable, high-performance name resolution services. Its global architecture ensures that DNS queries are served from the nearest available server, enhancing performance regardless of a user's location.

## Key Features

Azure DNS comes with several outstanding features:

1. **Global Reach**\
   Utilizing Azure's extensive network of data centers, Azure DNS serves queries from the closest server to ensure rapid response times.

2. **Security and Reliability**\
   Integrated with robust Azure security measures, Azure DNS ensures that your domain name resolution remains secure and highly reliable.

3. **Fast and Scalable**\
   With its ability to handle a high volume of DNS queries with low latency, Azure DNS automatically scales to meet your application's demands. This fully-managed service eliminates the need for manual server management.

## Benefits

Azure DNS not only improves performance but also delivers significant benefits that enhance your overall domain services management:

* **Managed Infrastructure**: Azure handles all backend operations, eliminating the need to maintain your own DNS servers.
* **Seamless Integration**: Integrates effortlessly with other Azure services like Virtual Machines and App Services.
* **Custom Domains**: Easily manage and host your custom DNS domains in a central, Azure-managed environment.
* **Automated Record Management**: Update DNS records through the Azure management APIs or the Azure Portal, streamlining the process and centralizing control.

## Use Cases

Azure DNS is ideal for managing domain needs associated with Azure-hosted applications. It ensures that your online services remain accessible and responsive by offering uninterrupted domain resolution. Common use cases include:

* Managing domain registration and record management.
* Hosting DNS records for applications running on Azure.
* Ensuring reliable domain resolution to improve website and application availability.
