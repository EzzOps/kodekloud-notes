# Course Introduction

Source: https://notes.kodekloud.com/docs/Crash-Course-AWS-Basics/AWS-Services/Course-Introduction/page

Beginner AWS course introducing cloud fundamentals, core services like EC2, S3, IAM, hands-on labs, practical examples and step-by-step guidance to build basic deployment skills.

Welcome — get ready to dive headfirst into the fascinating world of AWS. This beginner-friendly course breaks down cloud concepts into small, actionable lessons so you can learn AWS with confidence.

<Callout icon="lightbulb">
  No prior AWS or cloud experience is required. We'll begin with the fundamentals and build up to practical examples and hands-on exercises.
</Callout>

What to expect:

* Clear, beginner-focused explanations of core AWS concepts and services
* Practical examples and step-by-step guidance to reinforce learning
* A steady pace designed for newcomers so you can follow along without prior experience

Course roadmap (at a glance):

| Module         | Key topics                                            | Outcome                                                 |
| -------------- | ----------------------------------------------------- | ------------------------------------------------------- |
| Fundamentals   | Cloud basics, regions & availability zones, accounts  | Understand core cloud concepts and AWS global structure |
| Core Services  | EC2, S3, IAM, VPC basics                              | Learn essential AWS services and when to use them       |
| Practical Labs | Console walkthroughs, simple deployments, cost basics | Gain hands-on experience and basic deployment skills    |

Helpful links and references:

* [AWS Getting Started](https://aws.amazon.com/getting-started/)
* [AWS Documentation](https://docs.aws.amazon.com/)
* [Introduction to Cloud Computing](https://aws.amazon.com/what-is-cloud-computing/)
