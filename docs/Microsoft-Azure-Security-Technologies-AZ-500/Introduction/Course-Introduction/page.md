# Course Introduction

Source: https://notes.kodekloud.com/docs/Microsoft-Azure-Security-Technologies-AZ-500/Introduction/Course-Introduction/page

This course prepares you for the AZ-500 certification exam by exploring key aspects of Azure security technologies.

Welcome to the AZ-500 course on Microsoft Azure Security Technologies. I'm Rithin Skaria, your guide for this comprehensive journey into Azure security. This lesson is designed to prepare you for the AZ-500 certification exam by exploring key aspects of Azure security.

<Callout icon="lightbulb">
  Before starting this course, ensure you have:

  * A solid grasp of security best practices and foundational security principles.
  * Basic familiarity with the Azure platform.
  * Hands-on experience deploying Azure services such as virtual machines, databases, and networking.
</Callout>

This course is specifically focused on the security measures for Azure resources, not their deployment. Azure, being one of the most trusted cloud platforms, implements a shared security responsibility model between Microsoft and you as a customer. Protecting your data, applications, and infrastructure is essential.

## Key Learning Outcomes

By the end of this lesson, you will be able to:

* Secure Azure resources following industry best practices.
* Configure and manage identity and access effectively.
* Implement robust network security solutions.
* Monitor and promptly respond to security threats.
* Manage Azure security policies and procedures.
