# Why CNPE

Source: https://notes.kodekloud.com/docs/Prep-Course-Certified-Cloud-Native-Platform-Engineer-CNPE/Course-Introduction/Why-CNPE/page

Overview of a hands-on course preparing engineers for the Certified Cloud Native Platform Engineer performance exam covering platform architecture, GitOps, APIs, observability, and security

Welcome. This lesson explains why the Certified Cloud Native Platform Engineer (CNPE) certification matters and what this course will help you achieve. Whether you’re transitioning from DevOps, already building internal platforms, or pursuing the Kubestronaut title, this lesson provides the context and outcomes you can expect.

Platform engineering is more than a new job title — it’s a shift in how teams deliver developer productivity and operational consistency. Over time we’ve moved from manual system administration to DevOps practices and now to dedicated platform teams that design internal platforms, self‑service APIs, and automation to speed every engineering team.

Gartner predicts that 80% of large software engineering organizations will establish platform engineering teams by 2026. That trend is already visible across the industry.

The Cloud Native Computing Foundation (CNCF) introduced CNPE to validate the practical skills platform engineers need. Unlike multiple-choice exams, CNPE is performance-based: you’ll build, configure, and troubleshoot in a live environment. This proves you can execute the work required to design, operate, and evolve internal platforms.

What this course delivers

* Hands-on platform skills with demos and guided labs for every core concept.
* Tasks and scenarios mapped directly to the five CNPE exam domains to replicate the performance exam format.
* Real-world patterns: how architecture choices affect cost, how GitOps integrates with security, and how observability informs operations.
* End-to-end platform thinking: infrastructure, APIs, delivery pipelines, monitoring, and security.

Who this course is for

* DevOps engineers moving into platform engineering — you likely know Kubernetes and CI/CD; this course adds product thinking and platform design.
* Platform enthusiasts — learners who want structured coverage across the five CNPE domains.
* Kubestronaut seekers — CNPE is now part of the certification pathway for the Kubestronaut title.

Course mapping to CNPE exam domains

| CNPE Domain                            | Exam Weight | Core topics covered                                                                         |
| -------------------------------------- | ----------: | ------------------------------------------------------------------------------------------- |
| Platform Architecture & Infrastructure |         15% | Networking, storage, compute, cost optimization, multi-tenancy patterns                     |
| GitOps & Continuous Delivery           |         25% | GitOps workflows, CI/CD pipelines, progressive delivery, release strategies                 |
| Platform APIs & Self-Service           |         25% | CRDs & operators, Crossplane, developer-facing APIs, self-service provisioning              |
| Observability & Operations             |         20% | Monitoring, alerting, tracing, logging, incident response, runbooks                         |
| Security                               |         15% | RBAC, admission control, policy engines, service mesh considerations, supply chain security |

Each course section follows a consistent learning pattern to maximize exam readiness:

* Conceptual explanation of core ideas and trade-offs.
* Live demos illustrating common platform patterns and tools.
* Hands-on labs that mirror real tasks you’ll face in the CNPE exam.
* Exam-aligned task sets that build practical skills and confidence.

Further reading and references

* CNCF CNPE overview and exam page (check CNCF for the latest syllabus and exam details)
* [Kubernetes Documentation](https://kubernetes.io/docs/) for core concepts and APIs

By the end of this course you should be able to design platform architectures, implement GitOps pipelines, expose self-service APIs, operate observability stacks, and apply security controls — all with the hands-on experience needed for the CNPE performance exam.
